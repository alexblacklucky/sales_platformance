### 2026-06-28 · Деплой только через `main`
GitHub Pages отдаётся из ветки `main`. Прямой push в `main` заблокирован —
изменения попадают на сайт только через Pull Request → merge.
После merge ждать 1–2 минуты и обновлять страницу жёстко `Ctrl+Shift+R`.

### 2026-06-30 · Единый стиль дашбордов
Все дашборды — светлая фиолетовая тема. Канонический шаблон — `analytics/june.html`.
Тёмную тему не использовать.

### 2026-06-30 · Конверсия в контакт считается вручную
«Средняя конверсия в контакт» = суммарные контакты ÷ суммарные просмотры,
а НЕ среднее арифметическое конверсий профилей. В карточке обязательна пометка,
например: `223 / 3 017 — посчитано вручную (контакты ÷ просмотры)`.

### 2026-06-30 · Bitrix: что такое TOTAL / MEET / WON
- `TOTAL` = сумма сделок по **всем** колонкам канбана (включая «ОТВАЛИЛСЯ» и «Сотрудничество»).
- `MEET` = сумма 7 колонок: На презентации + Надо подумать + Моросят + Договор счёт +
  Сделка провалена + БОМЖИК ИКС 2 + Сделка успешна.
- `WON` = число успешных сделок, которое называет заказчик **вручную**
  (НЕ значение колонки «Сделка успешна»).

### 2026-06-30 · Форматирование чисел
Десятичные — через запятую, тысячи — через неразрывный пробел: `102 737,5 ₽`.

### 2026-06-30 · Ключевая связка метрик
Стоимость успешной сделки = расходы Avito ÷ `WON`.

### 2026-08-05 · Новые разделы сайта делаем по образцу «Менеджера по продажам»

регистрирует разделы в поиске и топбаре. Файлы для скачивания — в своей папке
(`manager/`, `contracts/`).

### 2026-08-05 · Не опираться на `--danger-soft` в тёмной теме
В базовой вёрстке сайта эта переменная не переопределена для тёмной темы (перебивает
более поздний `:root`), поэтому красные блоки получаются светлыми под светлым текстом.
Вместо неё использовать `color-mix(in srgb,var(--danger) 13%,var(--surface))`.
Переменные `--violet-soft`, `--surface`, `--line`, `--text` темизированы нормально.

### 2026-08-05 · Merge делает Claude, без вопросов

только обновить сайт через `Ctrl+Shift+R` через 1–2 минуты после merge.
Если изменение спорное или крупное — всё равно сначала показать, что вошло в PR.

### 2026-08-24 · Private-репозиторий выключает GitHub Pages насовсем
На бесплатном тарифе перевод репозитория в private отключает Pages, и возврат
в public его НЕ включает обратно. Чинится вручную: Settings → Pages → Source
«Deploy from a branch» → `main` / `(root)`, проверить Custom domain
`platformance-team.ru` и Enforce HTTPS. DNS при этом трогать не нужно.

### 2026-09-01 · Квалификация клиентов в Bitrix-дашборде (во всех месяцах)
В Bitrix-дашборд добавляется отдельная таблица «Квалификация клиентов» — доли всех
сделок месяца в процентах от `TOTAL`. Воронка `TOTAL`/`MEET`/`WON` остаётся как была.
Категории: **В работе, пока непонятно** (НОВЫЕ + Вопросы + Созвониться + Раскачиваю +
Договориться на видеовстречу + В работе сейчас + На презентации) · **Квал-лиды**
(Надо подумать + Моросят + Договор счёт + Сделка провалена + Сделка успешна) ·

**Последняя строка таблицы — «ИТОГО»**, и в ней в скобках всегда прописывается связка

### 2026-09-01 · Разовая правка канбана за август 2026

Также в колонке «Сделка успешна» осталось 7 карточек при 11 фактически закрытых сделках

### 2026-09-02 · Закрытый раздел «Зарплаты» — пароль в JS
Заказчик выбрал простой пароль в JS (константа `SALARY_PASSWORD` в `index.html`),

- **Приход** = сумма подписанных клиентов за месяц (лист «по месяцам» Google-таблицы

### 2026-09-02 · Премия продавца считается по периоду выплаты
База премии за месяц может не совпадать с суммой подписанных клиентов этого месяца:
клиент, подписанный в конце предыдущего месяца, попадает в премию следующего.
Например, август 2026: база премии 430 000 ₽ при 415 000 ₽ подписанных в августе —
разница это договор от 31.07, премию по нему выплатили в августе. **Это норма,
не расхождение** — не поднимать этот вопрос заново при сборке новых месяцев.
Приход в экономике при этом считается по дате договора (август = 415 000 ₽).
