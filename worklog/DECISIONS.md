### 2026-06-28 · Деплой только через `main`
GitHub Pages отдаётся из ветки `main`. Прямой push в `main` заблокирован —
изменения попадают на сайт только через Pull Request → merge.
После merge ждать 1–2 минуты и обновлять страницу жёстко `Ctrl+Shift+R`.

### 2026-06-30 · Единый стиль дашбордов
Все дашборды — светлая фиолетовая тема. Канонический шаблон — `analytics/june.html`.
Тёмную тему не использовать.

### 2026-06-30 · Конверсия в контакт считается вручную
«Средняя конверсия в контакт» = суммарные контакты ÷ суммарные просмотры,
а НЕ среднее арифметическое конверсий профилей. В карточке обязательна пометка,
например: `223 / 3 017 — посчитано вручную (контакты ÷ просмотры)`.

### 2026-06-30 · Bitrix: что такое TOTAL / MEET / WON
- `TOTAL` = сумма сделок по **всем** колонкам канбана (включая «ОТВАЛИЛСЯ» и «Сотрудничество»).
- `MEET` = сумма 7 колонок: На презентации + Надо подумать + Моросят + Договор счёт +
  Сделка провалена + БОМЖИК ИКС 2 + Сделка успешна.
- `WON` = число успешных сделок, которое называет заказчик **вручную**
  (НЕ значение колонки «Сделка успешна»).

### 2026-06-30 · Форматирование чисел
Десятичные — через запятую, тысячи — через неразрывный пробел: `102 737,5 ₽`.

### 2026-06-30 · Ключевая связка метрик
Стоимость успешной сделки = расходы Avito ÷ `WON`.

### 2026-08-05 · Журнал работы в репозитории
Заведена папка `worklog/`. Claude обязан читать её в начале каждой сессии и
обновлять в конце по команде «Завершаем работу». Журнал должен вливаться в `main`,
иначе следующая сессия его не увидит (репозиторий клонируется из `main`).

### 2026-08-05 · Рабочая ветка задаётся окружением
Имя рабочей ветки больше не фиксировано в `CLAUDE.md` — оно приходит из окружения
сессии и записывается в шапку `worklog/STATE.md` в конце каждой сессии.
