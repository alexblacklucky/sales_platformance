**Ветка:** `claude/start-work-c4jn43`

## Задача
Заказчик попросил планер-задачник: он сам записывает **проблемы** месяца, под каждой
— список решений с галочками, которые можно вычёркивать. Разбивка по месяцам,
но с возможностью видеть все месяцы сразу.

## Что сделано
- `planner-section.html` — вёрстка, стили и вся логика (в теге `<script id="pl-logic">`,
  при инжекте скрипт пересоздаётся, иначе из `innerHTML` он не исполняется).
- `injectPlannerSection()` в `index.html`, раздел добавлен в `reorderSidebar()`.
  Порядок сайдбара: Обучение → Материалы → Аналитика → **Планер** → Зарплаты.
- Возможности: добавить проблему (текст + месяц), шаги решения с чекбоксами
  (выполненные зачёркиваются), прогресс-бар, автостатус «РЕШЕНО» когда все шаги
  отмечены, переименование и удаление, фильтр по месяцам + режим «Все месяцы»
  с группировкой по месяцам, сводка (проблем / решено / шагов / выполнено).
- **Хранение — `localStorage`** (ключ `kb-planner-v1`): у сайта нет бэкенда.
  Данные не синхронизируются между устройствами и не видны сотрудникам.
  Поэтому добавлены **Экспорт / Импорт JSON** — бэкап и перенос. Ограничение
  описано прямо в разделе синей плашкой.
