# Сессия 2026-08-24 · Восстановление Pages + кнопки «Видеообучение»

**Ветка:** `claude/repository-public-site-sync-vsxmtn`
**PR:** #25, #26 (+ этот файл журнала — отдельным PR завершения)

## Что делали

### 1. Сайт не открывался после private → public
Заказчик случайно сделал репозиторий приватным, затем вернул публичным.
На бесплатном тарифе GitHub Pages при этом **отключается и сам не включается**.
- Диагностика: последняя сборка «pages build and deployment» была 12.08, свежих нет.
- Заказчик по инструкции заново включил Pages: Settings → Pages → Deploy from a
  branch → `main` / `(root)`, домен `platformance-team.ru` на месте, Enforce HTTPS.
- Сборка прошла успешно, сайт снова работает. Код не менялся, DNS не трогали.

### 2. Единая папка видеообучения на Google Диске
Папка: `https://drive.google.com/drive/folders/1nnvKLA4vlZCiGnA8WhaCKCotRnsG9Ipk`.
Задача: все кнопки видеообучения на сайте ведут на неё.
- **PR #25** — кнопка «Видео-инструкция» в «Менеджере по продажам»
  (`manager-section.html`): href заменён со старого архива (~1,9 ГБ одним файлом)
  на папку; подсказка под кнопками переписана («открой ссылку и выбери запись»).
- **PR #26** — две новые зелёные кнопки «Видеообучение» (стиль как `m-dl-video`):
  - «Создание договора» — в шапке раздела (`contracts-section.html`,
    добавлены классы `.c-dl-video`, `.c-ext`);
  - главная квалификатора «Роли и движение клиента» — страница зашита в
    закреплённый коммит `BASE_SITE_URL`, поэтому кнопка добавляется в рантайме:
    константа `VIDEO_TRAINING_URL` + функция `injectQualifierVideoButton(doc)`
    в `index.html` (вызов из `injectAnalyticsLink`).
- Кнопка «Основные файлы» не тронута — это другая папка (рабочие документы).

### 3. Проверка доступа к папке видеообучения
Доступ «всем, у кого есть ссылка» есть, но роль — **«Редактор»**: любой со
ссылкой может удалять/менять видео. Рекомендовано сменить на «Читатель»
(Google Диск → Настроить доступ). Заказчик пока не ответил — висит в бэклоге.
