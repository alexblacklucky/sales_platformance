# 🗂 worklog — журнал работы (бэклог) PLATFORMANCE

Папка-память проекта. Здесь фиксируется **всё, что мы делаем**: каждая сессия,
каждое изменение файлов, каждое решение и договорённость. Claude читает эту папку
в начале каждой сессии, поэтому ничего не теряется между заходами.

## Что где лежит

| Файл / папка | Назначение |
|---|---|
| `STATE.md` | **Главный файл.** Где мы сейчас: что готово, что на сайте, ключевые цифры, следующий шаг. Читать первым. |
| `BACKLOG.md` | Очередь задач: `СЕЙЧАС` → `ДАЛЬШЕ` → `ИДЕИ` → `СДЕЛАНО`. |
| `DECISIONS.md` | Решения и договорённости, которые нельзя забыть (как считаем, почему так, что не делаем). |
| `sessions/` | По одному файлу на сессию: что просили, что сделали, какие файлы тронули, чем закончили. |

Имена файлов сессий: `sessions/ГГГГ-ММ-ДД_NN_короткое-описание.md`
(`NN` — номер сессии за день: `01`, `02`, …).

## Протокол для Claude

### 🟢 В начале сессии («Старт работы» / «Начиная работу, возьми все данные»)

1. Прочитать `CLAUDE.md` и `ANALYTICS_GUIDE.md`.
2. Прочитать `worklog/STATE.md`, `worklog/BACKLOG.md`, `worklog/DECISIONS.md`.
3. Прочитать **последний** файл из `worklog/sessions/` (и предыдущий, если нужен контекст).
4. Проверить репозиторий: `git log --oneline -10`, состояние `analytics/`, ветку.
5. Отчитаться пользователю: **чем занимались до этого** → **что делаем дальше**
   → **какие файлы будем менять**. Затем спросить нужные данные и ждать.

### 🔵 По ходу сессии

Как только задача сделана (файл создан/изменён, коммит запушен) — сразу дописать
строку в файл текущей сессии в `sessions/`. Не копить до конца: если сессия
оборвётся, запись всё равно останется.

### 🔴 В конце сессии (команда «Завершаем работу»)

1. Дописать и закрыть файл текущей сессии в `sessions/` (итоги, что осталось).
2. Обновить `STATE.md` — состояние на текущий момент, дату, следующий шаг.
3. Обновить `BACKLOG.md` — перенести сделанное в `СДЕЛАНО`, поднять следующее в `СЕЙЧАС`.
4. Дописать `DECISIONS.md`, если по ходу появились новые правила/договорённости.
5. Обновить `CLAUDE.md` (раздел «На чём остановились»), если состояние поменялось.
6. Закоммитить и запушить в рабочую ветку, затем **PR → merge в `main`**.
   Merge Claude делает сам, спрашивать не нужно (решение от 05.08.2026).
7. Коротко отчитаться пользователю: что сохранено и с чего начнём в следующий раз.
   Напомнить обновить сайт через `Ctrl+Shift+R` спустя 1–2 минуты.

> ⚠️ Пункт 6 обязателен: новая сессия клонирует репозиторий из ветки `main`.
> Всё, что не влито в `main`, в следующей сессии **не будет видно**.
