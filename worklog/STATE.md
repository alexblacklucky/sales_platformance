## Открытые вопросы / известные баги

- **Доступ к папке видеообучения — «Редактор» для всех по ссылке.** Рекомендовано
  сменить на «Читатель». Ждём решения заказчика (с 24.08).
- **Тёмная тема, красные блоки в «Менеджере по продажам».** `.m-rule` использует
  `var(--danger-soft)`, не переопределённую для тёмной темы. Лечится заменой на
  `color-mix(in srgb,var(--danger) 13%,var(--surface))`. Отложено заказчиком.
- **Тестирование в браузере:** через внешний `BASE_SITE_URL` база знаний (4,6 МБ)
  рвётся на прокси. Для проверок поднимать локальный сервер с копией базы
  (`curl` файла + подмена `BASE_SITE_URL` на локальный путь).
