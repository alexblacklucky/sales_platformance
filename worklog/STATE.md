## Открытые вопросы / известные баги

- 🔴 **Проект полностью публичен** (аудит 06.09). Репозиторий `public`, сайт и все
  файлы отдаются анонимно; `salary-section.html` с зарплатами скачивается в обход
  пароля; пароль виден в исходниках и в истории git. Индексация запрещена
  (`robots.txt` + `noindex`, PR #40), но это не закрывает прямой доступ.
  Решение отложено заказчиком: Cloudflare Pages + Access либо GitHub Pro
  с приватным репозиторием. Детали и чек-лист — в `BACKLOG.md`.
- **Премия Дмитрия за Матвееву** (20 000 ₽ недоначислено в сентябре) — за октябрь
  зарплата дана итогом 146 000 ₽, вошла ли доплата, не уточняли.
- **Доступ к папке видеообучения — «Редактор» для всех по ссылке.** Рекомендовано
  сменить на «Читатель». Ждём решения заказчика (с 24.08).
- **Тёмная тема, красные блоки в «Менеджере по продажам».** `.m-rule` использует
  `var(--danger-soft)`, не переопределённую для тёмной темы. Отложено заказчиком.
- **Тестирование в браузере:** база знаний грузится с закреплённого коммита
  `BASE_SITE_URL` и рвётся на прокси. Для проверок: `git fetch --depth=1 origin 790d435…`,
  `git show 790d435…:index.html` в локальный файл, подмена `BASE_SITE_URL`,
  локальный `http-server`. Тестовые файлы не коммитить.
